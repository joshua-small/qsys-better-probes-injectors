Development draft — not a published release.

Adds probe/injector destinations to native Find by Context. Provides separate next/previous probe and injector commands, focused-tool navigation, home-component navigation, and explicit return-home through the native detach helper.

Commands register with Mods Core and have no default key assignments. Requires Core 0.1.6 or newer within 0.1.x and the exact supported Designer 10.5 build.

Offline build, behavior and metadata checks do not establish Designer acceptance. Computer Use, native UI, physical-key, Emulate/Run and hardware checks remain deferred. Catalog approval, package publication and installation have not occurred.
