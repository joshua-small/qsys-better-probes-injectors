# Better Probes & Injectors 0.1.3

Probe and injector keyboard/menu commands now stay inactive on UCI page canvases,
including derived UCI page types. Schematic and component-panel navigation retain
their existing behavior and default shortcuts.
Menu and toolbar actions revalidate their remembered canvas, and excluded UCI
canvases cannot fall through to an enclosing schematic canvas.

Adds portable regression coverage for canvas classification and navigation
lifecycle transitions. Native Find, focused Return Home and Core dependency
requirements are unchanged.

The exact DLL passed bounded Designer 10.5.0 checks for cycling, fresh UCI-control
exclusion/recovery, native Find Context for both tool types and local Emulate
Return Home with the other attachment preserved. A separate 10.5.1 smoke passed
using existing compatibility consent; package host hashes and compatibility
warnings are unchanged. Runtime attachment confirmation is visual. Retained-tool
plus true UCI-canvas focus was not demonstrated; live Core/hardware and native
Undo remain unverified. See the validation guide for the full scope.
