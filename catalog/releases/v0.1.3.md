# Better Probes & Injectors 0.1.3

Probe and injector keyboard/menu commands now stay inactive on UCI page canvases,
including derived UCI page types. Schematic and component-panel navigation retain
their existing behavior and default shortcuts.

Adds portable regression coverage for canvas classification and navigation
lifecycle transitions. Native Find, focused Return Home and Core dependency
requirements are unchanged. See the validation guide for application acceptance
and remaining limits.
