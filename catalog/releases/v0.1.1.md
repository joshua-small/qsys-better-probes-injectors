Adds default shortcuts: Ctrl+F11 / Ctrl+Shift+F11 for next/previous Probe, Ctrl+F12 / Ctrl+Shift+F12 for next/previous Injector, and Ctrl+Alt+H to return the focused tool home.

Defaults use Mods Core's shared shortcut registry. Existing custom or cleared bindings take precedence, and conflicting defaults remain inactive without overwriting another action. Find Focused and Find Home remain unassigned. Better Shortcuts is optional for customization.

Requires the same exact Designer 10.5.0 build and Mods Core >=0.1.6 and <0.2.0. Navigation and return-home behavior are unchanged. See docs/VALIDATION.md for scoped application acceptance and remaining limits.
